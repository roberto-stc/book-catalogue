# Book Catalogue

A PHP and MySQL website for browsing, adding, editing, deleting and searching books.
Built for my web development assignment and run on localhost with XAMPP.

## Running it on your computer

1. Install XAMPP and start **Apache** and **MySQL** from the XAMPP control panel.
2. Put this folder inside XAMPP's `htdocs` folder
   (Mac: `/Applications/XAMPP/htdocs/`, Windows: `C:\xampp\htdocs\`).
3. Open http://localhost/phpmyadmin, create a database called `book_catalogue`,
   click it, open the **SQL** tab, paste the contents of `sql/schema.sql` and click **Go**.
4. Visit http://localhost/book-catalogue/
